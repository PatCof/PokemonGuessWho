<h1>ℹ️ Overview of the Project</h1>
Pokemon Guess Who is an online Two-Player Game where each player would select their "Secret Pokemon"
 that their opponent would have to identify based on Yes or No questions.
<br>
Website Link: <b> [Pokemon Guess Who](https://pokemon-guess-who-delta.vercel.app/)</b>
<br>
⚠️ Due to the Limitations of Render (free ver.), the Backend will need 1 minute to jumpstart after pressing the button to create/join a Room so please standby.
<br><br><br>

<h1>📖 How to use the application </h1>
<ol> 1. Player 1 would create the Room by inputting their Display Name and pressing the Create button under Create Room. </ol>
<ol> 2. It would show a new screen displaying the Room ID that they would have to send to their friend. </ol>
<ol> 3. Player 2 would input the Room ID along with their Display Name and press the Join button. </ol>
<ol> 4. The Game Room would load and the Game would start.</ol>
<br><br>

<h1> 🎮 How it's played </h1>
<ol> 1. Once the board loads, Players take turns choosing their Secret pokemon by pressing on a Pokemon Card. </ol>
<ol> 2. The game will start with Players asking one Yes/No question and toggling Pokemon that does not fit that question. </ol>
<ol> 3. After their turn, Press the "End Turn" button to proceed with the next Player. </ol>
<ol> 4. Once a Player thinks they know their opponent's Secret Pokemon, they can press "Select Final Pokemon" button and select their final answer. </ol>
<ol> 5. Sending the Final Answer ends the game and a Winner will be chosen based on the Player's answer. </ol>
